# Android wrapper (minimal WebView, no Gradle)
- `./build.sh [out.apk]`: builds a debug-signed APK from `../dist-single` (needs JDK 17+, Android SDK build-tools 34 and platform 34 under `$ANDROID_SDK`, default `/opt/android-sdk`). Run `npm run build` first.
- The app runs fullscreen in portrait and works offline from the bundled `assets/www/index.html`. `navigator.vibrate` goes to native haptics through `window.AndroidHaptics`.
- **Updates (itch.io, no secret in the APK):** on launch the app loads the public page `ITCH_PAGE_URL` and finds the HTML5 embed folder (`https://html-classic.itch.zone/html/<id>/`). It reads `version.json` there, waiting at most 3 s. If that version is newer, it shows a pink "Updating…" screen with a progress bar, downloads `index.html` (the single-file build), loads it straight away, and shows the toast "Updated to vN ✨". If anything fails it uses the last downloaded copy or the bundled one. To publish: bump `public/version.json`, run `npm run build`, then `BUTLER_API_KEY=… ./itch-push.sh`. `UPDATE_BASE_URL` can point at any static folder instead.
